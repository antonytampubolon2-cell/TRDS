# TRDS — Educational Virtual Trading Simulator

**TRDS** is an educational virtual trading simulator engineered to help users understand financial market mechanics, develop risk discipline, and practice trading strategies in a safe, risk-free environment.

---

## ⚠️ Important Educational & Risk Disclaimer

- **Simulation Only**: TRDS is strictly an educational simulation platform.
- **No Real Money**: All balances, profits, losses, and transactions inside TRDS are 100% virtual. No real currency, fiat deposits, or actual cryptocurrencies/securities are traded or transferred.
- **Not Financial Advice**: Nothing within TRDS—including AI-generated analyses, market pulse metrics, indicators, or educational summaries—constitutes financial, investment, trading, or legal advice. TRDS does not provide buy/sell signals or guarantees of future performance. Always consult a licensed professional before engaging in real financial markets.

---

## 📊 Key Features

### 1. Market Pulse
Real-time visual monitoring of overall market sentiment, volatility indexes, and dynamic condition metrics across supported digital asset pairs.

### 2. TRDS AI Educational Analysis
An intelligent educational assistant that deconstructs complex technical indicators (such as RSI, Moving Averages, Support/Resistance zones, and volume flow) into clear, actionable learning concepts without relying on blind buy/sell signals.

### 3. Virtual Trading Simulator
A responsive, realistic trading workstation where users can practice executing trades against live simulated order feeds using a dedicated virtual cash balance.

### 4. Buy & Sell Simulation
Seamless practice for entering and exiting long and short positions, allowing users to experience price slippage, execution mechanics, and position sizing firsthand.

### 5. Stop Loss & Take Profit Education
Interactive parameter controls that teach users how to define defensive exit boundaries, protect virtual capital, and set rational profit targets before opening trades.

### 6. Risk Management & Trading Psychology
Built-in frameworks for position sizing, maximum drawdown rules, risk-to-reward ratio calculations, and psychological discipline checks to foster healthy trading habits.

### 7. Trade History & Journaling
A detailed historical log tracking all executed simulated trades, including execution timestamps, entry/exit levels, realized P&L, duration, and performance review metrics.

### 8. Premium Demo Mode
A demonstration tier showcasing advanced analytical modules, expanded indicator sets, and deep-dive educational features designed for structured learning.

## 📡 Market Data Notice

All asset prices, candlestick charts, quotes, and volume metrics presented in this application are **simulated data** generated for demonstration, training, and educational workflows. They do not represent live executable exchange order books.

## 🚀 Getting Started (Local Setup)

Follow these steps to run TRDS locally on your machine:

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) (bundled with Node.js)

### Installation & Run

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Launch the Development Server**
   ```bash
   npm run dev
   ```

3. **Access the Application**
   Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
